# Components

> 本文将介绍小程序中封装好的，提供给其他组件或直接使用的公共组件的接口。

小程序中封装的所有公共组件应放置在`pages/components`目录下

## Empty

- 引用路径：`Empty.vue`
- 用法场景：该组件是当用户暂时没有数据的一个空状态的提示
- 具体参数

| name     | type                              | desc                |
|----------|-----------------------------------|---------------------|
| message  | string                            | 空状态primary提示信息      |
| iconType | "success" \| "warning" \| "error" | 空状态类型，目前支持：成功、警告、错误 |
| hint     | string?                           | 空状态secondary提示信息    |
