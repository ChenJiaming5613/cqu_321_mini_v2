# 页面设计稿对齐计划

本文记录 `分页面设计稿/` 下各页面设计稿与当前实现的对应关系、开发优先级和实现边界。

## 基础约定

- 右侧刷新按钮只出现在具备明确刷新动作的页面，例如课表、考试安排、生活；成绩查询不使用右上刷新，后续优先通过下拉刷新或页面内更新状态处理。
- 首页底部栏暂时只保留首页和我的两个入口；设计稿中间图表类入口对应功能页暂缓开发。
- 体测查询、志愿时长、空教室页面暂缓开发，但首页保留入口，点击弹窗提示“敬请期待”。
- 使用教程和关于我们采用“Vue 页面壳 + 本地 Markdown 正文”的混合方案。导航栏、logo、页面背景、间距等必须排版由 Vue/CSS 控制，正文内容继续用 Markdown 管理。
- 选课信息页面暂缓真实功能。文档已确认 iOS 选课接口小程序暂不接入，如需展示，先做未登录/不可用态。

## 共享组件优先级

1. `src/pages/components/NavigationBar.vue`
   - 参考所有二级页面设计稿顶部栏。
   - 支持返回按钮、居中标题、背景建筑图、可选右侧刷新按钮。
   - 通过事件暴露刷新动作，不在组件内写业务逻辑。
2. `src/pages/components/Empty.vue`
   - 参考 `成绩管理 2.jpg`、`考试安排 1.jpg`、`生活.jpg`、`志愿时长.jpg`、`体测查询.jpg`。
   - 支持标题、说明、可选按钮。
   - 暂时使用 CSS 和现有图标近似插画，不阻塞后续替换真实图片资源。
3. 首页暂缓入口
   - 体测查询、志愿时长、空教室保留按钮。
   - 点击统一弹窗提示“敬请期待”。
