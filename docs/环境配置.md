## 1. Project Settings

1. 打开终端，切换到你要放置该项目的路径，输入以下命令：

~~~shell
git clone https://gitee.com/platopeanut/cqu321-mini-v2.git
# 或者
git clone https://github.com/platopeanut/cqu321-mini-v2.git
~~~




2. 安装项目依赖：

~~~shell
npm install
~~~

​	如果出现安装依赖失败的情况，请先查看[Uniapp Vite-TS](https://gitee.com/dcloud/uni-preset-vue/tree/vite-ts/)模板项目是否有更新依赖，如果发现有更新，请及时联系项目负责人，之后进行相应更改。



3. 运行程序：
   1. 运行`package.json`文件中`dev:mp-weixin`命令，项目编译后会在项目根目录产生`dist/dev/mp-weixin`目录
   2. 打开微信开发工具，选择导入，将`dist/dev/mp-weixin`导入
   3. 在导入项目配置页面，项目名称修改为如`321CQU Dev`，AppID选择为321CQU的AppID
   4. 进入项目后，点击`编译`可在模拟器上对小程序进行预览
   5. 点击`预览`可以通过扫描二维码的方式在真实物理手机上进行预览




3. 由于微信小程序以及Uniapp这一个体系的HTML区别于浏览器上的HTML，比如描述尺寸的单位是`rpx`（浏览器上的是`px`），因此Webstorm会在页面中报单位错误。所以需要安装适配于微信小程序的插件：[Uniapp Tool]([Uniapp Tool - IntelliJ IDEs Plugin | Marketplace (jetbrains.com)](https://plugins.jetbrains.com/plugin/21470-uniapp-tool)) （可以直接在插件市场搜索安装）

   

4. 此外，如果插件未能成功解析时，可以手动补充（慎重！一定要确保你补充的是正确的）

## 2. Tech Stack

本项目（微信小程序第二版）是基于[Uniapp CLI]([uni-app官网 (dcloud.net.cn)](https://uniapp.dcloud.net.cn/quickstart-cli.html))的[Vite-TS](https://gitee.com/dcloud/uni-preset-vue/tree/vite-ts/)版本构建。所用到的技术栈如下：

- [Vue3](https://cn.vuejs.org/guide/introduction.html)
  - 我们强制使用**组合式 API (Composition API)**风格开发

- [Typescript](https://www.typescriptlang.org/)
  - 类型约束在复杂项目中十分有用！

- [微信小程序文档]([开始 | 微信开放文档 (qq.com)](https://developers.weixin.qq.com/miniprogram/dev/framework/quickstart/getstart.html))
- [Uniapp文档]([uni-app官网 (dcloud.net.cn)](https://uniapp.dcloud.net.cn/))



### 2.1 UI

此外，我们目前使用的UI框架是**ColorUI**（以后可以考虑全部样式由自己写）目前选用这套UI的原因是他是他的设计思想与[Tailwind CSS](https://www.tailwindcss.cn/)一样，只通过封装一个个样式类，做到了轻量、灵活、非侵入。因此我们可以逐步接入我们的UI。

如果考虑继续沿用ColorUI，请先克隆[ColorUI Github](https://github.com/weilanwl/coloruicss)项目到本地自定义目录，打开`Colorui-UniApp/pages`目录即可查看对应的示例代码，并在微信上搜索`ColorUI组件库`结合示例代码一起参考



## 3. Packing & Upload

小程序会经历如下几个版本阶段：

- 开发版本：开发人员可以预览和使用
- 体验版本：开发人员和体验成员可以使用
  - 可以在要提交正式版本之前，组织体验成员进行内测，排查和优化程序中的bug
- 正式版本：所有人可以使用

在完成一个版本的开发需要正式将代码上传到微信小程序平台的时候，请按照如下步骤进行打包和上传：

1. 运行`package.json`中的`build:mp-weixin`命令生成正式版本的代码，这种代码相比于`dev`模式代码体积会被压缩，以及一些代码优化
2. 编译完成后会在项目根目录下生成`dist\build\mp-weixin`目录，导入到微信开发工具中
3. 编译运行预览，检查正式版本与开发版本之间是否存在差异，一定要在物理机上做测试
4. 点击`上传`，填写更新类型，版本号（版本号命名规范详情请查看[版本号命名规范](./命名规范.md#版本号命名规范)），项目备注信息后上传代码（此时小程序从开发版本提交到体验版本）
5. 在[微信公众平台](https://mp.weixin.qq.com/)的版本管理中将体验版本提交审核，审核通过后就可以发布正式版本
